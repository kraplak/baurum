Предпочитаемые источники

Codex учитывает их первыми. Приоритет — ведическая астрология / Джйотиш. Все выдачи на русском.

Пока не сохранено. В MVP сохраняется локально в этом браузере.

Как Codex это использует

Codex сначала проверяет эти ресурсы, приоритизирует Джйотиш-темы и отмечает связь с камнями только там, где она естественна. Хорошие невыбранные темы уходят в локальный банк источников.

Ручной цикл с Codex

Без токенов и автоматического расхода баланса. Codex ищет реальные статьи в чате, вы выбираете темы, затем Codex пишет посты и заносит их в Google Sheet.

ручной режим
Нажмите «Запрос Codex», чтобы сформировать задание на 20 новых статей. Внешние ключи не используются.

Импорт подборки Codex

Когда Codex пришлёт 20 найденных статей, вставьте JSON сюда. Сайт сохранит ссылки в локальный банк, чтобы не показывать одно и то же в следующих поисках.

поиск 0

Можно вставить JSON-массив или объект {"topics":[...]}.
